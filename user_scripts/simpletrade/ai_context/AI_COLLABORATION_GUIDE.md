# SimpleTrade AI协作指南

**最后更新**: 2023-10-15

## 1. 概述

本文档提供了如何使用SimpleTrade项目的AI上下文管理框架与AI助手进行高效协作的详细指南。这个框架旨在减少重复说明上下文的需求，保持项目信息的一致性，并提高AI协作的质量和效率。

## 2. 文件结构

```
user_scripts/simpletrade/ai_context/
├── PROJECT_STATUS.md       # 项目当前状态和进度
├── CURRENT_FOCUS.md        # 当前工作重点和任务
├── DECISIONS_LOG.md        # 关键决策记录
├── AI_COLLABORATION_GUIDE.md  # 本文档
├── SESSION_SUMMARIES/      # 会话摘要目录
│   ├── session_YYYYMMDD_1.md
│   ├── session_YYYYMMDD_2.md
│   └── ...
└── REFERENCE/              # 参考资料
    ├── API_OVERVIEW.md     # API概览
    ├── DB_SCHEMA.md        # 数据库结构
    └── ...
```

## 3. 工作流程

### 3.1 开始新会话

1. **准备上下文信息**:
   - 确保`PROJECT_STATUS.md`和`CURRENT_FOCUS.md`是最新的
   - 如果有特定的参考资料需要提供，准备好相关文件

2. **启动会话**:
   复制以下模板，填入相关内容，并发送给AI:

   ```
   我正在开发SimpleTrade项目，这是当前项目状态和工作重点:
   
   [粘贴PROJECT_STATUS.md内容]
   
   [粘贴CURRENT_FOCUS.md内容]
   
   基于以上信息，我们今天需要[具体任务描述，如"开始编写测试计划文档"]。
   ```

3. **提供额外上下文(按需)**:
   - 如果AI需要了解某个特定决策的背景:
     ```
     这是关于[决策名称]的详细信息:
     
     [从DECISIONS_LOG.md中粘贴相关部分]
     ```
   
   - 如果需要参考之前的会话:
     ```
     这是我们上次关于[主题]的讨论摘要:
     
     [从SESSION_SUMMARIES中粘贴相关内容]
     ```
   
   - 如果涉及特定代码或文档:
     ```
     这是相关的[文件类型]:
     
     [粘贴相关文件内容]
     ```

### 3.2 会话中

1. **保持焦点**:
   - 参考`CURRENT_FOCUS.md`中的任务列表，确保会话围绕当前优先事项进行
   - 如果出现新的问题或决策点，记录下来以便更新到相应文件中

2. **增量工作**:
   - 每次会话专注于少量明确的任务，而不是尝试一次解决所有问题
   - 确保每个任务都有明确的完成标准

3. **记录关键决策**:
   - 当做出重要决策时，记下决策内容、原因和替代方案
   - 会话结束时将这些决策添加到`DECISIONS_LOG.md`

### 3.3 结束会话

1. **生成会话摘要**:
   在会话结束前，要求AI生成摘要:
   
   ```
   请为本次会话生成一个摘要，包括讨论内容、决策、生成的代码/文档和下一步计划。
   ```

2. **保存会话摘要**:
   - 将AI生成的摘要保存到`SESSION_SUMMARIES/session_YYYYMMDD_N.md`
   - 其中YYYYMMDD是日期，N是当天的会话序号

3. **更新状态文件**:
   - 更新`PROJECT_STATUS.md`中的进度信息
   - 更新`CURRENT_FOCUS.md`中的任务状态
   - 如有新决策，添加到`DECISIONS_LOG.md`

4. **保存所有文件**:
   - 确保所有生成的代码和文档都已保存到正确的位置

## 4. 文件维护指南

### 4.1 PROJECT_STATUS.md

**更新频率**: 每次会话后

**更新内容**:
- 项目阶段变化
- 已完成/进行中/待开始工作的状态
- 最近会话记录
- 下一步计划

**示例更新**:
```markdown
## 已完成工作
- ✅ 测试计划文档编写 (`doc/test_plan.md`)

## 进行中工作
- 🔄 部署和运维文档编写 (进度: 50%)

## 最近会话
- [2023-10-16] 完成了测试计划文档的单元测试部分
```

### 4.2 CURRENT_FOCUS.md

**更新频率**: 每次会话后，或任务优先级/状态变化时

**更新内容**:
- 任务状态变化
- 新增任务
- 本周目标调整
- 下一步具体行动

**示例更新**:
```markdown
## 活跃任务
1. **测试计划文档编写**
   - 状态: 进行中 -> 已完成
   
2. **新任务名称**
   - 优先级: 高
   - 状态: 待开始
   - 描述: 任务描述
   - 相关文件: `相关文件路径`
```

### 4.3 DECISIONS_LOG.md

**更新频率**: 做出新决策时

**更新内容**:
- 新决策的详细信息
- 决策日期
- 决策原因
- 替代方案
- 影响

**示例更新**:
```markdown
## 2023-10-16: 决策名称
**决策**: 具体决策内容
**原因**: 
- 原因1
- 原因2
**替代方案**: 其他可能的选择
**影响**: 这个决策对项目的影响
```

## 5. 最佳实践

1. **保持文件简洁**:
   - 定期审查状态文件，移除不再相关的信息
   - 将旧的会话摘要归档，保持当前文件的简洁

2. **一致的格式**:
   - 遵循既定的格式和结构
   - 使用Markdown格式化文本，提高可读性

3. **及时更新**:
   - 每次会话后立即更新相关文件
   - 不要积累未记录的变更

4. **版本控制**:
   - 将ai_context目录纳入版本控制
   - 这样可以追踪项目状态的变化历史

5. **定期回顾**:
   - 每周回顾项目进度和AI协作效果
   - 根据需要调整协作流程和文件结构

## 6. 故障排除

1. **AI不理解上下文**:
   - 检查提供的信息是否完整
   - 尝试提供更具体的信息或示例
   - 确保文件内容是最新的

2. **协作效率低下**:
   - 检查任务是否定义清晰
   - 确保CURRENT_FOCUS.md中的优先级正确
   - 考虑将大任务分解为更小的步骤

3. **信息不一致**:
   - 定期审查所有状态文件，确保信息一致
   - 解决文件之间的任何矛盾
